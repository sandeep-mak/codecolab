# 🚀 CodeColab: Real-Time Collaborative Workspace

**CodeColab** is a comprehensive, real-time collaborative coding environment and social platform built for developers, study groups, and technical interviews. It seamlessly combines the live-syncing power of a modern IDE with the communication and proctoring tools of a professional workspace.

Whether you are pair-programming, diagramming cloud architectures on a shared whiteboard, or conducting a secure technical assessment, CodeColab keeps everyone in sync with sub-second latency.

### ✨ Key Features

  * **Multiplayer Editor:** Real-time code synchronization and live cursor tracking powered by Yjs (CRDT) and WebSockets.
  * **Live Python Execution:** Compile and run Python code directly within the shared secure environment.
  * **Proctored Exam Mode:** An admin-toggled assessment mode featuring tab-switch detection, clipboard paste restrictions, and real-time proctor alerts for secure technical interviews.
  * **Visual Collaboration:** Built-in real-time interactive whiteboard for system design and architecture diagramming.
  * **Communication Suite:** Peer-to-peer WebRTC voice chat and persistent in-environment text chat.
  * **Social Graph & Teams:** Global user search, friend requests, group creation, and persistent group chats with a real-time notification system.
  * **Granular Security (RBAC):** Share environments via 6-digit Quick-Join codes with strict Read/Write/Execute permission controls and comprehensive Admin Audit Logs.
  * **Smart AI Assistant:** Integrated Google Gemini AI to debug, explain, and optimize code contextually.

### 🛠️ Tech Stack

  * **Frontend:** React 18, TypeScript, Vite, TailwindCSS, Monaco Editor, Yjs, Konva.js.
  * **Backend:** Java 21, Spring Boot 3.x, Spring WebSockets, Spring AI.
  * **Database & Cache:** PostgreSQL 18, Redis.
